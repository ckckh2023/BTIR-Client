# BTIR 鸿蒙客户端 · 智瞳医脑

BTIR 的鸿蒙手机客户端，用于脑部 MRI 病例上传、分析结果查看、随访对比和报告导出。客户端需要连接 BTIR 服务端，使用同一服务端账号可查看对应的病例与分析任务。

## 下载鸿蒙客户端

当前鸿蒙版本为 **v26.1.0**。

- **[下载鸿蒙 HAP 测试包](https://github.com/ckckh2023/BTIR-Client/releases/download/HarmonyOS-Mobile-v26.1.0/BTIRClient-HarmonyOS-v26.1.0.hap)**
- [查看鸿蒙 Release 与更新说明](https://github.com/ckckh2023/BTIR-Client/releases/tag/HarmonyOS-Mobile-v26.1.0)

请选择上面的 `.hap` 安装包；Release 中的 **Source code** 是项目源码，无需下载它来安装客户端。

## 安装与登录

需要 HarmonyOS 5 及以上系统。测试包能否安装取决于包的签名及目标设备授权，请先联系安装包提供者确认。下载 HAP 并不代表任意手机都能直接安装。

打开客户端后，使用所连接服务端的账号登录；没有账号时，可在注册入口创建账号。使用自部署服务时，请将服务器地址设为管理员提供的地址。可在登录页点击“服务器地址”修改并保存。

## 开始使用

### 上传病例

1. 在首页选择“开始上传病例”。
2. 选择一种上传方式：

   - **病例 ZIP**：压缩包内包含 FLAIR、T1CE、T1、T2 四模态 NIfTI 文件，或对应的 DICOM 序列。DICOM 文件夹请先压缩为 ZIP。
   - **四模态 NIfTI**：分别选择 FLAIR、T1CE、T1、T2 对应的 `.nii` 或 `.nii.gz` 文件。

3. 按需补充病例名称、检查日期等信息，点击“开始数据分析”。
4. 在病例列表或任务详情中查看进度，完成后查看分析结果和切片预览。

没有测试文件时，可在上传页选择“下载测试样例”，保存一个 BraTS 样例 ZIP，再返回上传页选择该文件。每次上传一个病例 ZIP；下载样例本身不会创建分析任务。

### 管理病例与复查

- **查看检查**：在“病例列表”中查看同一病例下的检查记录。
- **新增复查**：在原病例下选择“新增复查”，上传本次检查，避免将同一人的复查建为独立病例。
- **随访对比**：打开任务详情，在“随访对比”中选择一份已完成的历史检查作为基线。
- **重命名与归档**：在检查卡片的“管理”中操作。归档后可在“已归档”中恢复；彻底删除前请确认，删除后无法恢复。归档记录的可恢复期限以页面提示为准。

### 导出报告

分析完成后，打开任务详情，选择“查看与导出报告”，等待预览加载，再点击“保存 PDF”选择保存位置。报告包含该次检查已有的分析结论与影像预览；仅部分分析完成时，报告可能不包含全部结果。

鸿蒙端目前提供切片预览，暂不提供完整三维交互查看。分析结果用于辅助参考，不替代专业人员的临床判断。

## 常见问题

| 问题 | 处理方式 |
| --- | --- |
| 登录或请求失败 | 检查网络、服务器地址及账号信息；使用自部署服务时，向管理员确认服务是否可用。 |
| 鸿蒙手机无法安装 | 确认系统版本、安装包签名、设备授权和测试包有效期，联系安装包提供者处理。 |
| 上传失败 | 确认 ZIP 能正常解压，或四模态文件已选齐；保留完整错误提示后重试。 |
| 报告暂时不可导出 | 等待任务完成，再重新打开报告预览。 |

仍有问题时，可[提交问题反馈](https://github.com/ckckh2023/BTIR-Client/issues)，注明系统版本、客户端版本、复现步骤及完整错误提示。截图请遮盖账号和病例个人信息，不要提交密码或原始病例资料。
