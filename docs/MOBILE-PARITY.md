# 鸿蒙端与网页端体验对齐清单

> 后续排版与交互调整已进入 1.1.1，参见 [新版逐页对齐记录](WEB-INTERACTION-PARITY.md)。下方保留 1.1.0 的实现与测量记录。

参考：主服务端 `frontend/app.js`、`frontend/analysis-progress.js` 与当前接口模型。

主要目标：相同服务端状态下，阶段、结论、量化数据与网页一致；临时断网、页面切换和迟到响应不会使界面停滞或回退。

## 本轮实施与验收

- [x] 进度映射统一为上传 0–10、分类 10–20、分割 20–90、汇总 90–99；仅服务端确认成功才到 100。
- [x] 阶段标签按实际任务阶段更新，排队和取消不提前完成模型；快慢任务平滑、不倒退。
- [x] ZIP、四模态及模态重选上传显示结构化上传进度，平滑衔接分析页。
- [x] 详情页请求串行；临时网络失败退避重试；401/403/404 停止；30 分钟超时可手动恢复。
- [x] 页面隐藏停止轮询与动画；回来立即刷新；迟到响应与重试前的旧结果失效。
- [x] 病例列表在前台有活动任务时自动刷新，保留列表并处理迟到响应，操作按钮有明确忙碌状态。
- [x] 综合结论使用 `level`/`label` 与结构化证据，旧接口有保守回退，页面与 PDF 一致。
- [x] 显示病灶范围、最大横截面积、WT/TC/ET 体积；零值显示为 0，缺失值显示为“—”。
- [x] 随访兼容单独返回的推荐基线，并明确基线日期、变化方向和零基线的百分比处理。
- [x] 切片按真实层号命名，限量并发、逐张显示、缓存与失败重试；支持原图/叠加和放大查看。
- [x] PDF 同步综合结论与量化指标，保留预览缺失提示，防止重复准备及迟到响应。
- [x] 统一配色、卡片、间距与按钮尺寸；长文案/大字体使用自适应高度，减少首屏次要信息。
- [x] 登录/注册与改密页可滚动；服务器地址持久保存，切换时校验地址并清除旧账号上下文。
- [x] 文件下载释放连接并设置超时；真机上传错误提示不再要求启动模拟器工具。
- [x] 专项回归覆盖进度、断网恢复、乱序响应、离页、结论、零值、基线、预览并发与连接清理；通过 ArkTS 构建。

## 修改前基线

- 固定合成状态：排队 raw=36、分割开始 raw=44、分割中 raw=71、汇总 raw=99。
- 手机显示：36、44、71、99；网页映射：10、20、55、90（网页另有有界插值）。
- 两个合成回放缺陷均复现：一次网络失败停止轮询；迟到 running 覆盖较新 failed 并恢复轮询。
- 综合结论忽略结构化 level；“高概率不存在”文本会误入 present 分支。
- 图片串行且整批完成才显示；零体积被真假判断隐藏。
- CPU、内存、真机实际耗时与真实故障率：未测量。

```bash

  --input dist/BTIR-HarmonyOS-v1.1.0-unsigned.hap \
  --certificate .signing/BTIR-round2.cer \
  --profile .signing/BTIR-round2.p7b \
  --output dist/BTIR-HarmonyOS-v1.1.0-signed.hap
```
