# 鸿蒙端网页体验对齐（1.1.1）

参考主项目 `frontend/index.html`、`about.html`、`guide.html`、`theme.css` 与 `assets/guide.md`。保留鸿蒙原生文件选择、视频播放、PDF 保存；3D 查看继续隐藏。

## 本轮差异与改动

| 页面/部分 | 之前的差异 | 本轮调整 |
| --- | --- | --- |
| 顶栏 | 子页 Logo 在右侧，登录页居中 | 固定左侧 16vp 起始位置；标题在其后，右侧统一放返回/页面操作 |
| 首页 | 两张大入口卡片，上传多走一步 | 登录后直接打开病例分析工作区；分析/任务管理保持同一导航层级 |
| 上传 | 样例按钮在首屏顶部，操作分散 | 上传区下方提供“首次体验？下载测试样例”；文件未齐时禁用分析；上传期间锁定切换；分析按钮随表单滚动 |
| About | 多张分离卡片，缺少网页内容层级 | 单一正文面板、横排品牌区、项目简介/标签、能力网格、协作与贡献者、仓库选择面板 |
| 样例页 | 只有视频及下载卡片 | 视频→文件名/大小/下载按钮→使用说明→三组基准结果，采用网页边框和按钮层级 |
| 样例核对 | 完全缺失 | 同网页 61.27%、71.65%、73.74% 与各 WT/TC/ET（cm³）；注明允许推理浮动 |
| 结果 | 分类、分割长列表在前，随访很靠后 | 综合结论→随访→影像学关键特征→模型依据→当前层预览→辅助分析 |
| 概率曲线 | 手机端缺少网页曲线 | 使用服务端真实层号和概率，显示阈值、阳性比例，可触摸选择切片；缺数据时隐藏 |
| 影像特征 | 仅范围、面积和体积 | 补充瘤周水肿、强化成分、空间分布；分母为零或缺数据不编造占比 |
| 切片预览 | 所有原图/叠加图依次堆叠 | 当前层原图/叠加切换、上一层/下一层及真实层号，保留全屏查看 |
| 随访 | 所有历史基线默认展开 | 当前/推荐基线优先，历史检查折叠选择，零基线不显示无穷大百分比 |
| 明细/导出 | 明细长且导出主按钮占首屏 | 区域明细折叠，导出在顶栏，技术信息保留在底部展开 |
| 统一样式 | 圆角和强主按钮过多 | 网页 10vp 卡片/6vp 按钮圆角、同色边框、44vp 触控区域和自适应文本高度 |
| 登录/改密 | Logo 与布局另成一套 | 同一固定顶栏，登录表单保留独立白色面板，账号控制保留原有校验 |

## 验收

- `node tests/mobile-parity.cjs`：18 项通过、0 失败、0 跳过，包括直接与网页 `guide.html` 比较样例概率/体积、源 ZIP 大小，以及曲线真实层号、非法数值过滤和零分母处理。
- ArkTS debug 构建成功，仍有工程既有的旧 API/潜在抛错警告，并非零警告构建。
- 隔离模拟器使用本机合成接口及虚构数据，验证登录直达分析页、固定 Logo、About 内容与仓库面板、样例说明和三组基准、结果阅读顺序、顶栏报告入口、下一层与原图切换；四模态表单和表单内分析按钮位置。
- 主界面、About、样例页、结果页的 Logo 实测 UI 边界均为 `[48,134][180,266]`（1320×2232 测试屏幕），固定在同一左上位置。
- 概率曲线实际显示折线、阈值虚线及真实切片信息；修正了绘图组件未明确尺寸时只显示标记点的问题。
- 切片预览从 `1 / 3 · 切片 142` 切换到 `2 / 3 · 切片 143`，切换原图仍保留当前层。
- 本轮不向正式服务器提交病例；未复测真机安装、长时间运行、所有大字体/横屏组合。

## 构建产物

`dist/BTIR-HarmonyOS-v1.1.1-unsigned.hap` 用于本轮交付；已核对包名、版本、路由及内置视频。保留既有 `1.1.0-signed.hap` 与旧稳定包。

```bash
python3 tools/btir-sign-latest
```
